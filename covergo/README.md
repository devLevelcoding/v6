# CoverGo tracking artifacts

Mirrors of the sprint plan pushed into LaraCRM (project 22 / epic 37) by
`laracrmctl` (which lives at `F:\V5\GoAdmin\laracrmctl`, not in this repo).

| file | what |
|---|---|
| `covergo-concepts.yaml` | the sprint spec — one sprint per Go concept (U#/P#), tasks per service |
| `covergo-progress.txt`  | task-status manifest — `laracrmctl statuses-db` applies it |
| `covergo-blockers.txt`  | per-task blocker comments — `laracrmctl comments-db` posts them |

The narrative + benchmark tables are in [`../CoverGo.md`](../CoverGo.md).
